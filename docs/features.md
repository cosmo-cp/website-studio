# Features

Cosmo Studio focuses on speed, clarity, and control. Below is a practical overview of the core capabilities you can expect today.

## Multi-provider support

Connect multiple AI providers and switch between them without changing tools. Cosmo Studio supports OpenAI, Anthropic, Google, and Ollama so you can choose the right model for each task.

## Modern chat experience

A clean, distraction-free interface helps you stay focused on the conversation. Messages render with full Markdown support, including code blocks and tables.

## Local-first history

Your conversations are stored locally, making it easy to revisit past work without uploading content to a third-party service by default.

## Provider management

Add, edit, and remove providers with simple configuration flows. Keep keys organized and update settings when your needs change.

## Cross-platform availability

Run the same experience on Windows, macOS, and Linux with consistent behavior across all supported platforms.

## Roadmap items

- **Multimodal input:** Planned support for image-based prompts.
- **Expanded integrations:** More model providers and productivity workflows.
