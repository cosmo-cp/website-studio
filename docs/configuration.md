# Configuration

Cosmo Studio lets you manage providers, models, and preferences from a centralized settings panel.

## Provider setup

1. Open **Settings**.
2. Select **Providers**.
3. Choose a provider and add your API key.
4. Save changes to activate the provider.

## Model selection

- Choose a default model per provider for faster chat creation.
- Switch models per conversation to compare output quality or cost.

## Preferences

- Adjust theme and interface settings for focus.
- Review storage options if you want to change local history behavior.

## Security recommendations

- Store API keys securely and rotate them periodically.
- Use separate keys for personal and team usage.
- Restrict API keys at the provider level when possible.
