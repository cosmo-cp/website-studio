# Installation

Cosmo Studio is available for Windows, macOS, and Linux. Choose the installer that matches your operating system and follow the process below.

## System requirements

- A modern 64-bit operating system (Windows 10+, macOS 12+, or a recent Linux distribution)
- Internet access for model providers that require API calls and model information

## Install on Windows

1. [Download](https://cosmocp.com/) the Windows installer.
2. Run the installer and follow the setup wizard.
3. Launch Cosmo Studio from the Start menu.

## Install on macOS

1. [Download](https://cosmocp.com/) the macOS build.
2. Extract the downloaded zip and drag Cosmo Studio into **Applications**.
3. Launch Cosmo Studio from Launchpad or Finder.

## Install on Linux

1. [Download](https://cosmocp.com/) the Linux package for your distribution.
2. Install the package using your system package manager.
3. Launch Cosmo Studio from the app menu.

## Verify your install

Open Cosmo Studio and confirm you can reach **Settings** > **Providers**. If the app launches and the settings screen loads, you are ready to connect a provider.
