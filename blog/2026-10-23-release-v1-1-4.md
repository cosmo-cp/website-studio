# 🚀 Cosmo Studio 1.1.4: Bring ACP Agents Into Your Workspace

Today we’re celebrating the release of **Cosmo Studio 1.1.4**. This update brings local agents built on the **Agent Client Protocol (ACP)** into your Cosmo workflow, so you can discover supported agents, check their connections, and work with them from chat.

<!-- truncate -->

## Meet ACP agents in Cosmo Studio

ACP gives compatible agents a standard way to connect with a client. In Cosmo Studio, an ACP agent runs as a local process and receives a workspace for its session. Its responses stream into Cosmo chat, where you can switch between the **Model** and **Agent** runtimes.

### Find and set up an agent

Open **Settings → Agents → Registry** to browse the public ACP registry. You can search entries, review their distribution type, and install supported `npx` or `uvx` agents. Once installed, use **Test connection** to check that Cosmo can initialize an ACP session.

Enable an agent in Settings, then open a chat and switch the composer from **Model** to **Agent**. Choose an agent and provide a workspace path, or use its configured default workspace, to get started.

### A clearer place to manage your setup

Version 1.1.4 also brings agent and feature configuration together under **Settings** and includes refactors to chat history and state handling.

## Get started with 1.1.4

Download Cosmo Studio for [macOS, Windows, or Linux from the 1.1.4 release page](https://github.com/cosmo-cp/cosmo-studio/releases/tag/v1.1.4). Then follow the [ACP agent guide](/docs/features#agent-client-protocol-acp-) for setup and usage details.

Thank you to everyone building with Cosmo Studio and sharing feedback. We’re excited to see what you do with agents in your workspace.
