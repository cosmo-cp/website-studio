# 🚀 Cosmo Studio 1.1.5: Resilient Model Discovery & Per-Chat Streaming

Today we’re excited to announce the release of **Cosmo Studio 1.1.5**. This update delivers background chat streaming across navigation, brings robust model discovery through the official `@opencode-ai/models` SDK with offline fallback, and hardens ACP agent session execution.

<!-- truncate -->

## Per-chat streaming lifecycle

In previous versions, switching between conversations while a model or agent was generating could interrupt the active response. With Cosmo Studio 1.1.5, responses now stream through isolated per-chat sessions that continue in the background.

- **Switch freely**: You can start a generation in one conversation, move to another chat, check documentation, or tweak settings without interrupting ongoing responses.
- **Dedicated session controls**: Each conversation maintains its own status indicators, activity feedback, and independent stop/abort controls.
- **Safe concurrency**: Multiple conversations can now stream concurrently while ensuring strict per-chat request boundaries and race-free state hydration.

## Resilient model discovery with Models.dev SDK

To provide a faster, more dependable model discovery experience across your cloud providers, Cosmo Studio has transitioned from raw REST API endpoints to the official `@opencode-ai/models` SDK.

- **Offline and degraded network support**: If live catalog queries fail or you are working offline, Cosmo seamlessly falls back to a bundled snapshot of provider models.
- **Accurate metadata**: Automatically hydrates up-to-date capability metadata, including context windows, output limits, reasoning capabilities, multimodal input/output support, and tool calling across supported providers.

## Hardened ACP agent subprocess lifecycle

Building upon the ACP agent integration introduced in v1.1.4, version 1.1.5 introduces stronger isolation and resource governance:

- **Isolated subprocess leases**: ACP agent requests now operate in dedicated subprocess leases per conversation.
- **Automatic idle cleanup**: Idle agent sessions are safely retained per conversation and automatically stopped after 5 minutes of inactivity to keep your system resources light.
- **On-demand Node runtime**: Registry `npx` agents utilize a shared, verified on-demand Node.js and npm runtime checked against pinned checksums.
